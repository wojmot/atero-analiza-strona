atero_analiza

Private, non-commercial data analysis project

atero_analiza is a small, private, non-commercial project for analysing the reach and engagement of a music artist's content. With the artist's explicit consent, the project reads public profile information and content statistics (such as views, likes and comments) from TikTok, YouTube and Spotify, and uses them for data analysis as part of a personal portfolio and educational project.

The project uses TikTok Login Kit and the Display API with the scopes user.info.basic, user.info.stats and video.list. The data is not sold, not shared with third parties and not used for advertising.
